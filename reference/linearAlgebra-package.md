# linearAlgebra: Linear Algebra Helpers

Vectorization and half-vectorization of matrices, symmetric matrices
from their half-vectorization, the duplication matrix
\\(\boldsymbol{D}\_{k}\\) and its Moore-Penrose inverse, deviation
scores, and tests for symmetric and positive definite matrices. Each
exported function has an internal version without input checks that
other projects can copy.
